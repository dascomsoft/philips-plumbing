# Philip's Plumbing Website

##  Overview

This is a professional 5-page website developed for **Philip's Plumbing**, a family-owned, PIRB-registered plumbing company based in Johannesburg, South Africa. The site was built to showcase their services, display project galleries, and provide customers with easy access to emergency plumbing assistance 24/7.

## Technologies Used

- HTML5
- Tailwind CSS (via CDN)
- AOS (Animate On Scroll) library
- Font Awesome 6 icons
- Google Fonts (Inter)
- JavaScript (vanilla)

## Project Structure

```
philip-plumbing/
│
├── index.html          # Homepage with hero section, stats, and featured content
├── services.html       # Complete list of plumbing services with descriptions
├── about.html          # Company history, values, team, and milestones
├── gallery.html        # Project gallery with modal image viewer
├── contact.html        # Contact page with forms and business information
│
└── images/             # Client's project images
    ├── plumbing10.webp
    ├── Geyser-Installations.jpg
    ├── Leak-Detection.jpg
    ├── Maintenance-Work.jpg
    └── ... (additional project images)
```

## 📱 Features

- **Fully Responsive** - Optimized for mobile, tablet, and desktop viewing
- **Clean Navigation** - Sticky header with mobile hamburger menu
- **Emergency Call Bar** - Fixed bottom bar on mobile for instant contact
- **Image Gallery** - Clickable images with modal pop-up and descriptions
- **WhatsApp Integration** - Direct chat links throughout the site
- **Animated Scroll** - Smooth AOS animations for better user experience
- **Contact Forms** - Quick quote forms that open WhatsApp pre-filled

## Design Highlights

- Dark theme with gold/yellow accents (brand colors)
- Professional, trust-building layout
- Large typography that scales down on mobile
- Clear calls-to-action on every page
- Client's actual project images used throughout
